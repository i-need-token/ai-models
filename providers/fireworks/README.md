# Fireworks AI

Fireworks AI is an inference platform providing serverless and dedicated endpoint hosting for open-source and proprietary AI models, with fast inference speeds.

## Data Sources

- **Pricing**: https://fireworks.ai/models (SSR page, browser-verified)
- **Model IDs**: Fireworks API & docs
- **Context lengths**: Fireworks models page

## Notes

- Fireworks AI is an **inference platform**, not a model producer. All models are from other providers.
- Pricing shown is Fireworks AI's serverless per-1M-token rate (USD).
- Only serverless models with explicit per-token pricing are included.
- On-demand models using tier-based pricing (by parameter count) are excluded because the tier assignment depends on model configuration details not available from the pricing page alone.
- Tier-based pricing: Up to 16B $0.50/$1.00, 16.1B-80B $3.00/$6.00, 80B-300B $6.00/$12.00, >300B $10.00/$20.00 per mtok.
