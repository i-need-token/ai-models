# DeepInfra

DeepInfra is an inference platform providing serverless and dedicated endpoint hosting for a wide range of open-source and proprietary AI models.

## Data Sources

- **Pricing**: https://deepinfra.com/pricing (SSR page, browser-verified)
- **Model IDs**: DeepInfra API & docs
- **Context lengths**: DeepInfra pricing page

## Notes

- DeepInfra is an **inference platform**, not a model producer. All models are from other providers.
- Pricing shown is DeepInfra's per-1M-token rate (USD).
- Some models have prompt caching pricing (`cache_read` field).
- Voxtral audio models use `UnitPricing per_request` (per-second pricing approximated).
- Only LLM models from the pricing page are included.
- DeepInfra also offers image generation, embeddings, and other model types not included here.
