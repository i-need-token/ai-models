# SiliconFlow CN

Chinese version of [SiliconFlow](https://siliconflow.cn), hosting models from other providers with CNY per-token pricing.

## Data Source

- **Pricing**: Browser-scraped from https://siliconflow.cn/models (CNY per 1M tokens)
- **Model IDs**: SiliconFlow CN website
- **Context lengths**: Cross-referenced with official provider documentation

## Notes

- All pricing is in CNY (Chinese Yuan), making this one of few providers with CNY pricing in the catalog
- "Pro/" variants (dedicated deployment) are excluded — same model, same price, just guaranteed availability
- Free models (￥0/￥0) with small size or specialized purpose are excluded
- Models hosted: DeepSeek, Qwen (3.6/3.5/3/2.5), GLM, MiniMax, StepFun, InclusionAI, ByteDance Seed, Tencent Hunyuan
- The API requires authentication via API key
