# Scaleway

European cloud provider offering Generative APIs with per-token pricing in EUR.

## Data Source

- Pricing page: https://www.scaleway.com/en/generative-apis/
- API docs: https://www.scaleway.com/en/developers/api/generative-apis/

## Pricing

All prices are in EUR per million tokens.

## Notes

- Scaleway is a European cloud provider (based in France, GDPR-compliant)
- Offers both chat/completion and embedding models
- Uses OpenAI-compatible API
- Pricing is in EUR, not USD
