# SiliconFlow

SiliconFlow (硅基流动) is an inference platform providing serverless hosting for a wide range of open-source and proprietary AI models.

## Data Sources

- **Pricing**: https://siliconflow.com/pricing (SSR page, browser-verified)
- **Model IDs**: SiliconFlow API & docs
- **Context lengths**: SiliconFlow pricing page

## Notes

- SiliconFlow is an **inference platform**, not a model producer. All models are from other providers.
- Pricing shown is SiliconFlow's per-1M-token rate (USD).
- Some models have prompt caching pricing (`cache_read` field).
- Only LLM models from the pricing page are included.
- SiliconFlow also offers image generation, video generation, and audio models not included here.
- The pricing page shows "Load More" buttons for some model families — only the initially visible models are included.
