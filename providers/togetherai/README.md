# Together AI

Together AI is an inference platform providing serverless and dedicated endpoint hosting for open-source and proprietary AI models.

## Data Sources

- **Pricing**: https://together.ai/pricing (SSR page, browser-verified)
- **Model IDs**: Together AI API & docs
- **Context lengths**: Together AI docs (most models support 128k)

## Notes

- Together AI is an **inference platform**, not a model producer. All models are from other providers.
- Pricing shown is Together AI's per-1M-token rate (USD).
- Some models have prompt caching pricing (`cache_read` field).
- Model IDs use the `provider/model-name` format from Together AI's API.
- The pricing page lists 25 LLM chat models, 1 embedding model, and 1 rerank model.
- Only LLM chat models are included in this catalog.
