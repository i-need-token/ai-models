# SubModel

GPU cloud and inference platform offering per-token pricing for popular open-source models.

## Data Sources

- **Model list & pricing**: https://submodel.ai homepage (MaaS section)
- **Context lengths**: SubModel homepage model cards

## Notes

- SubModel is a GPU cloud + inference platform, not a model producer
- Models hosted are from Qwen, ZhipuAI, OpenAI, and DeepSeek
- API requires authentication; model list obtained from homepage
- Per-token USD pricing with no cache pricing listed
- Some models have "Free Quota" (free tier) but pricing shown is the paid rate
- 6 models available as of 2026-05-16
